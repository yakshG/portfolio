OVERVIEW

A 2D platformer with shooting mechanics, patrolling enemies, collectible coins, and level hazards. Built while learning Unity's 2D toolset and C# scripting fundamentals.

WHAT I BUILT

Level Design

  • 2 custom levels using Unity's tilemap system and rule tiles for rapid prototyping.
  • Interactive elements: ladders for vertical traversal, bounce mushrooms with incremental jump height, and traps.
  • Exit portals connecting levels with game session persistence.

Player Systems

  • Movement, jumping, shooting mechanics with bullet instantiation.
  • Ladder climbing system with collision detection.
  • 3-lives system with respawn at level start on death.
  • Animation states and transitions for player and enemy sprites.

Enemy & Hazards

  • Enemy patrol AI using collision detection for ground edges and direction reversal.
  • Enemy collision with player reduces lives and triggers respawns.
  • Enemies destroyed on bullet hit with death animation.
  • Environmental traps and hazards that trigger player death.

Game Flow

  • Lives system: player respawns at current level start after death with level state preserved.
  • Full restart to level 1 after all lives are lost.
  • Coin collectible system with score tracking across levels.
  • Cinemachine state-driven camera following player with smooth zoom transitions.

Technical Setup

  • Composite colliders for sprite interactions.
  • Prefab variants for reusable level elements (enemies, hazards, collectibles)
  • Game session controller managing level transitions and persistent score.
  • Scene management system for level loading.

WHAT I LEARNED

  • Unity's 2D workflow: tilemaps, rule tiles, sprite rendering, and collision systems.
  • Lives system and game state management across levels
  • Object instantiation and projectile mechanics
  • Cinemachine camera systems for smooth transitions.
  • C# scripting fundamentals: component architecture, event systems, and game loop structure.
