OVERVIEW

A fast-paced tactical shooter for 2-4 players in local co-op. Players compete in deathmatches across 4 maps using modular weapons (knife, pistol, rifle) and power-up pickups that alter player physics. The player with the most kills when the 3-minute timer ends wins.

MY CONTRIBUTIONS

Core Gameplay Systems

  • Health management and damage calculation
  • Score tracking with kill/death/point statistics
  • Re-spawn system using designer-placed spawn points with randomization
  • Weapon switching between knife, pistol, and rifle (semi-auto/auto)
  • Aim assist for controller support

Local Multiplayer Infrastructure

  • Character selection menu with first-come-first-serve locking that updates UI across all controllers in real-time
  • Player controller possession with delayed initialization to handle non-default controller spawning
  • Restart logic that properly removes all local players and clears split-screen views

Weapons & Power-Ups

  • Base weapon system extended for power-up pickups that replace the pistol slot
  • Reviewed and integrated teammate implementations of physics-altering effects (size scaling, anti-gravity, slippery movement)

Animations

  • Recorded knife attack animations using Xsens mocap software
  • Retargeted mocap data to player skeleton and blended animations using Animation Blueprints
  • Integrated and refined player animations in Blueprints for smooth combat feel

Deployment

  • Built and published game to Steam

End-Match-UI

  • Final scoreboard displaying player names, kills, deaths, and calculated points

KEY CHALLENGES

Challenge: Character locking in local multiplayer

Real-time UI updates across all controllers when one player locked a character. Broadcasting events to all player controllers and updating buttons states dynamically.

Challenge: Controller possession timing

Non-default controllers failed to possess pawns on creation. Fixed by adding delayed possession after successful player controller initialization.

Challenge: Local multiplayer debugging

Tracking bugs across 4 simultaneous players and split-screen views. Use of breakpoints and systematic variables tracking and logging strategies.
