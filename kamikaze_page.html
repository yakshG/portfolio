OVERVIEW

Kamikaze is a 2-4 player local split-screen tactical deathmatch shooter. Players compete in a 3-minute deathmatch across four maps using a modular weapon system (knife, pistol, rifle) where highest score wins.

I was the solo programmer for the first half of development and later transitioned into Lead Programmer.

MY CONTRIBUTIONS

Core Systems

  • Centralized all match flow inside GameMode:
    • Score tracking per player
    • Timer management
    • Win condition logic
    • Randomized respawn handling

Local Multiplayer

  • Built the full local multiplayer pipeline:
    • Multi-controller input handling
    • PlayerController → Pawn possession
    • Player-specific spawn assignment

Weapon Systems

  • Designed a modular weapon system using a shared base class.
  • Derived Weapons:
    • Knife (3 melee animations)
    • Pistol
    • Rifle (semi-auto & auto)
  • Base class extended for power-up pickups that replace the pistol slot

Animations

  • Helped record mocap animations.
  • Integrated and refined animations using Unreal's Animation Blueprint.

Character Selection Locking

  • Designed a first-come-first-serve character selection system:
    • Selected characters lock immediately
    • UI dynamically updates availability
    • Lock state tied to player index

Steam Build & Publishing

  • Handled production builds, packaging issues, and final Steam deployment.

TECHNICAL CHALLENGES

Challenge: Pawn Possession in Local Multiplayer

Problem: PlayerControllers were failing to properly possess spawned pawns due to incorrect initialization timing.

Solution: Traced Unreal's lifecycle flow and used post-initialization function call to ensure proper order of:

  • PlayerController initialization
  • Pawn spawning
  • Possession execution
