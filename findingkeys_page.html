OVERVIEW

A 2-player online co-op puzzle game set in a stylized Egypt environment. Both players must find and collect keys hidden throughout the level to unlock the main pyramid door. Puzzles require coordination: pressure plates, moving platforms, and locked doors are all designed around players working together.

Built to learn online multiplayer development in Unreal Engine 5.5.

What I Made

Puzzle Layout

  • Pressure plate system: plates triggered by players or moveable boxes placed around the level. Plates must stay active, releasing any plate closes the linked door immediately.
  • Key collection & door logic: main pyramid door requires all 4 keys. A secondary door requires 3 simultaneous pressure plates (one player, two boxes), creating a coordination puzzle where one player holds while the other fetches the key.

Multiplayer Subsystem

  • Built a custom GameInstanceSubsystem in C++ handling session creation, discovery, joining, and destruction for both LAN and Steam.
  • Automatic LAN/Steam detection on initialization: if Steam is running and configured, the subsystem uses Steam; otherwise falls back to LAN via NULL subsystem.
  • LAN: host creates a named session, client searches by name and joins directly.
  • Steam: session joined via overlay invite using OnSessionUserInviteAccepted — client automatically travels on invite acceptance.

Level Design

  • Single level set in a stylized Egypt environment using free assets from Fab.
  • Layout designed around co-op dependency: key puzzles are intentionally unsolvable without both players present.
  • Vertical traversal via moving platforms gated behind pressure plate coordination.

POST MORTEM

Challenge: Steam session joining silently failing in UE5.5

Problem: Sessions were found and returned correctly, but joining via Steam consistently failed with no error — the join call succeeded internally but the client never traveled to the host.

Solution: The default OnlineSubsystemSteam configuration did not work in net driver initialization. Switching to the Steam Sockets plugin and updating the net driver to SteamSocketsNetDriver helped, but the fix also required adding specific session settings during discovery — without those settings present in the search result, the client had no information to resolve the connection string and never traveled.
